# OpenConcord

**Pre-alpha.** OpenConcord is an open-source project exploring secure, self-hostable collaboration between people and AI agents across workspaces, machines, sessions and MCP-compatible clients.

The goal is continuity and independently checkable evidence across **existing** tools. OpenConcord does not aim to replace your terminal, Git, sandbox manager or agent framework.

**Planned modes:** Observe, Collaborate, Orchestrate and Validate. These are design directions, **not yet implemented product features**. No public networking, account registration or production-ready access control is available yet.

The eventual community core must work locally without a paid account or proprietary cloud dependency. All project integrations, upstream components and their licenses will be assessed before implementation and public release.

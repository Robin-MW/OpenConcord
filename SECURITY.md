# Security policy

**Pre-alpha:** OpenConcord is not presently a supported production service. Do not expose experimental terminal or agent-control interfaces on the public internet or use them with sensitive data.

For security-sensitive reports, use GitHub's private vulnerability reporting feature if enabled on this repository. If it is not available, do not disclose credentials, vulnerabilities or confidential material in a public issue; contact a maintainer through a nonpublic channel first.

No security response-time or coordinated-disclosure SLA is promised at this stage.

# Security policy

**Pre-alpha:** OpenConcord is not presently a supported production service. Do not expose experimental terminal or agent-control interfaces on the public internet or use them with sensitive data.

Submit vulnerabilities through GitHub private vulnerability reporting at https://github.com/Robin-MW/OpenConcord/security/advisories/new. Maintainers must enable and verify this private reporting route before accepting vulnerability reports or publicly distributing functional code. If the route is disabled or unavailable, **do not create a public issue containing vulnerability details**. Use an independently verified private contact listed by the repository owner, if available; until one is confirmed, private reporting is blocked and requires maintainer action. Never share credentials in reports.

No security response-time or coordinated-disclosure SLA is promised at this stage.

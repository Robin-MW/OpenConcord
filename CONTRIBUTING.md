# Contributing to OpenConcord

OpenConcord is **pre-alpha**. Bug reports, design critiques, documentation improvements and narrowly scoped tests are welcome.

Before a contribution is accepted, its provenance and licensing must be clear. Do not submit code, assets, logs, fixtures or secrets from employers, customers, private repositories or other upstream projects unless you are authorized to redistribute them under compatible terms.

## Contribution process

1. Discuss substantial architecture changes in an issue before implementing them.
2. Keep changes small, deterministic and independently testable.
3. Explain source provenance, third-party licenses, supported platforms, and any new permissions or external network effects.
4. Treat the source as AGPL-3.0-only unless a file says otherwise.

**Contributor-rights policy is not yet finalized.** No contributor agreement or copyright assignment is required or implied by this document. Contributors retain their own copyright; external code contributions needing commercial relicensing will require separate, explicit agreement from the rights holder. Maintainers must not assume that a pull request grants relicensing rights.
